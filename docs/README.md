# 文档索引

代码之外的东西都放这里：**怎么跟学校那几套系统打交道**（接口协议），以及**当初为什么这么设计**。

> 所有接口结论来自实际探测，**校方随时可能改**。
> 与代码冲突时以代码为准；发现过期欢迎提 Issue 更正。
>
> ⚠️ 本目录下的接口文档**只记录协议结构**：不含账号、密码、Cookie、令牌、学号，
> 也不含能定位到具体住户的用电实测值（所有读数一律写成 `XXX.XX`）。
> 域名是学校官网上能查到的公开系统地址，原样保留；南校区电费站的裸 IP 在正文里写成
> `183.169.***.***`，**完整地址只出现在代码里**（`SchoolConfig.URL_SDCX_SOUTH` 与
> `network_security_config.xml`）—— 那是 App 连得上它所必需的，不是机密。

## 不在本仓库里的东西（以及为什么）

- **原始抓包与页面 dump**（`.har`、cookie 文件、模拟器截图）：**不入库也不随源码分发**。
  它们包含登录令牌与个人数据，协议结论已固化到上面的接口文档里，删包不丢信息。
- **本机构建 / 装机的环境笔记**：含本机路径与设备信息，不入库。通用部分见根目录
  `README.md` 的「构建」一节。
- **内部协作文档**（排期表、清理清单等开发过程记录）：属维护者内部资料，不入库。
- **上游郑大版的部分调研文档**（`郑大校园助手-接口现状核查.md` 等）：本仓库是河南理工适配版，
  这些调研针对的是郑大系统，未随源码分发。`design/` 各篇开头的"配套/前置"引用因此可能指向缺失文件，
  属历史沿革，不影响正文阅读。
