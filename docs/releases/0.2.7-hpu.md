河南理工版（HPUPocket）的第一个预发布包，基于 [ZZUPocket](https://github.com/rainthink-vanilla/HAUTPocket) 移植（上游为郑州大学版，MIT 许可）。

> [!WARNING]
> **这是 debug 签名的测试包，不是正式发布签名。** 升级会踩坑，务必先读下面的「签名变更警告」。

## 已经能用的

- **统一身份认证登录**：走学校 CAS，只保存加密令牌，**不保存密码**
- **教务课表**：学期 / 教学周切换、周次表头带日期（今天高亮）、冲突课程占位、自定义日程可与教务课混排
- **宿舍电费**：楼栋 → 楼层 → 房间三级联动（房间号取自学校字典，不内置房间表）
- **空闲教室**：按楼筛选，看每间教室哪几节有课
- **桌面小组件 3 个**：下一节课（2×2）、今明课表（4×2）、周课表（可缩放）
- **显示偏好**：字号五档（跟随系统 / 小 / 标准 / 大 / 特大）、周末延长开关（多出一列空的"周八"）、
  小组件密度、启动图标六种配色、存储清理

## 还不能用的

- **图书馆（座位 / 研讨间）：本版没有这个功能。** 协议已测绘，但三条路都没走通 ——
  WebVPN 对 `seatlib` 整站（含 `/rest/*`）302 拦截、`/rest/auth` 要求明文凭据（与只用 Cookie
  的登录方式冲突）、还有 5 项细节需真机验证。记录见
  [hpu-library-protocol.md](https://github.com/unusename-886/HPUPocket/blob/main/docs/interfaces/hpu-library-protocol.md)。
- **校园卡**：按需求不做。
- **电量 / 校园卡小组件**：未实现，当前只有上面三个课表类小组件。

## 安装

- 需要 **Android 12（API 31）及以上**
- `applicationId` 是 `com.hpupocket.app`，与郑州大学版不同，**两版可在同一台手机共存**，数据互不影响
- 首次安装要走系统的「未知来源应用」授权；Flyme / MIUI 还需在「设置 → 应用 → 权限」里
  给文件管理器或浏览器放行「安装未知应用」

## 签名变更警告

本包用 **debug keystore** 签名，仅供试用与验证。等河南理工版接入稳定后会换成独立的 release keystore，
**届时签名变更，必须先卸载旧包再装新包，本地数据（课表缓存、电费房间号、专注记录）会全部丢失。**

想长期用的话建议自己用 Android Studio 构建 —— 同一台机器的 debug 签名是固定的，可以一直覆盖安装。

## 反馈

接口结论来自公开网页的协议整理，**随时可能因学校调整而失效**。登录或数据拉取失败时，
请附上「更多 → 诊断」里的日志片段提 Issue，别只写"用不了"。
