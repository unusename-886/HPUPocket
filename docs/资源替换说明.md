## 1. 启动器图标

### 当前状态（✅ 已接入用户素材，2026-11-19）
- `res/mipmap-anydpi-v26/ic_launcher.xml` / `ic_launcher_round.xml`：自适应图标，引用
  `background=@color/ic_launcher_background`、`foreground=@drawable/ic_launcher_foreground`、
  `monochrome=@drawable/ic_launcher_monochrome`。
- `res/drawable-nodpi/ic_launcher_foreground.png`：用户提供的猫咪图，等比缩放居中到
  108dp 画布的安全区（432×432 PNG，四周留白露背景色）。
- `res/drawable-nodpi/ic_launcher_monochrome.png`：同形白色剪影（A13 主题图标）。
- `values/colors.xml` / `values-night/colors.xml` 的 `ic_launcher_background` = `#C8D7F6`
  （取自猫图同款浅蓝，前景自带底色，过渡无缝）。
- 原上游占位矢量（蓝块×绿块）已删除，避免同名 PNG/XML 冲突。

### 后续替换方式（若要换成校徽/官方图标）
- **PNG**：直接覆盖 `drawable-nodpi/ic_launcher_foreground.png`（≥432×432，主体在中间安全区）；
  同步更新 `ic_launcher_monochrome.png` 为同形白色剪影，并改两个 colors.xml 的背景色。
- **矢量**：改用 108×108 viewport 的 vector XML，需删除同名 PNG（二选一，不能并存）。
- 无需改代码——`@drawable/ic_launcher_*` 引用不变，换文件即生效。

### 素材来源
用户于 2026-11-19 提供（灰白卡通猫脸、浅蓝底），已裁切/去背处理为自适应图标；
原始图仅存于用户会话，仓库内只保留处理后的图标资源。
